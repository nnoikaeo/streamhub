# เชิญผู้ใช้จากไฟล์ CSV

admin ส่ง template ให้แต่ละบริษัทกรอกรายชื่อ บริษัทส่งไฟล์ CSV กลับมา แล้ว admin นำเข้าที่ `/admin/invitations` → **เชิญหลายคน** → **📤 นำเข้า CSV** ระบบไม่ส่งคำเชิญเองตอนนำเข้า แถวที่ผ่านจะเข้ารายการให้ตรวจก่อน แล้ว admin กด **ส่ง** เหมือนการกรอกทีละคน

ตกลงกับทีม One Data เมื่อ 2026-11 ([roadmap.md](roadmap.md#meeting--2026-11-one-data-asks-admins-to-set-who-a-user-is))

## คอลัมน์

เรียงตามนี้เท่านั้น ถ้าหัวคอลัมน์ไม่ตรง ระบบปฏิเสธทั้งไฟล์

| คอลัมน์ | กรอก | ระบบตรวจ |
|---|---|---|
| ชื่อ | ไม่บังคับ | สะกดตามคอลัมน์ ชื่อ-สกุล ใน PIC |
| นามสกุล | ไม่บังคับ | |
| บริษัท | **รหัส**บริษัท เช่น `STSB` | ต้องเป็นรหัสที่มีใน StreamHub ระบบไม่รับชื่อบริษัท |
| กลุ่ม 1, กลุ่ม 2, กลุ่ม 3 | ชื่อกลุ่ม ช่องละ 1 กลุ่ม | ต้องเป็นกลุ่มที่มีใน StreamHub ถ้าบทบาทเป็น admin ระบบจะละกลุ่มทิ้ง |
| gmail | `somchai.j@gmail.com` หรือ `somchai.j` | รับเฉพาะ `@gmail.com` และต้องไม่ซ้ำกันในไฟล์ |
| บทบาท | `user`, `moderator` หรือ `admin` | ภาษาไทยหรือคำอื่นไม่ผ่าน |

แถวที่ไม่ผ่านจะขึ้นในกล่องแดง พร้อมเลขแถวตามที่เห็นใน Sheets และเหตุผลทุกข้อ แถวที่ว่างทั้งแถวจะถูกข้าม นำเข้าได้ครั้งละไม่เกิน 500 แถว

## สร้าง template บน Google Sheets (ทำครั้งเดียว)

ไฟล์ CSV เก็บ dropdown ไม่ได้ template จึงต้องอยู่บน Google Sheets

1. ที่หน้า **เชิญหลายคน** กด **📄 ดาวน์โหลด template** (ได้หัวคอลัมน์และแถวตัวอย่าง) และกด **📥 ดาวน์โหลดรายการรหัส** (รหัสบริษัท ชื่อกลุ่ม และบทบาทที่มีอยู่ตอนนี้)
2. สร้าง Google Sheets ใหม่ด้วยบัญชี admin ตั้งชื่อแท็บแรกว่า `กรอกข้อมูล` แล้ววางไฟล์ template ลงไป
3. เพิ่มแท็บ `รายการ` แล้ววางไฟล์รายการรหัสลงไป (คอลัมน์ A รหัสบริษัท, C กลุ่ม, D บทบาท)
4. ในแท็บ `กรอกข้อมูล` ตั้ง dropdown ด้วย Data → Data validation → Dropdown (from a range):
   - คอลัมน์ C (บริษัท): `รายการ!A2:A`
   - คอลัมน์ D–F (กลุ่ม 1–3): `รายการ!C2:C`
   - คอลัมน์ H (บทบาท): `รายการ!D2:D`
   - ทุกช่องเลือก **Reject input** เพื่อไม่ให้พิมพ์ค่าอื่นทับ
5. ล็อกแท็บ `รายการ` (Data → Protect sheets and ranges) ให้แก้ได้เฉพาะ admin
6. เอา URL ของชีตไปใส่ใน `INVITE_TEMPLATE_SHEET_URL` ที่ [inviteCsv.ts](../../app/utils/inviteCsv.ts) ปุ่ม **↗ เปิด template** จะขึ้นในหน้าเชิญหลายคน ถ้าค่านี้ยังว่าง ปุ่มจะซ่อนอยู่

เมื่อมีบริษัทหรือกลุ่มใหม่ ให้ดาวน์โหลดรายการรหัสอีกครั้งแล้ววางทับแท็บ `รายการ` ส่วนสำเนาที่ส่งให้บริษัทไปแล้วจะไม่อัปเดตตาม

## ส่งให้บริษัทกรอก

1. เปิด template → File → **Make a copy** แล้วแชร์สำเนาให้คนกรอกของบริษัทนั้น
2. เขากรอกแท็บ `กรอกข้อมูล` แล้วเลือก File → Download → **Comma-separated values (.csv)** ระบบจะดาวน์โหลดแท็บที่เปิดอยู่ จึงต้องเปิดแท็บ `กรอกข้อมูล` ก่อน
3. ส่งไฟล์กลับให้ admin นำเข้า

กรอกใน Excel แทนได้ ให้บันทึกเป็น **CSV UTF-8** ถ้าบันทึกเป็น CSV ธรรมดาบน Windows ภาษาไทย ระบบก็อ่านออกเหมือนกัน เพราะจะอ่านไฟล์เป็น `windows-874` ให้เองเมื่อไฟล์ไม่ใช่ UTF-8 แต่ Excel ไม่มี dropdown ของ template ระบบจึงจับค่าที่พิมพ์ผิดได้ตอนนำเข้าเท่านั้น

## ทำไมยังไม่รับ .xlsx

repo ยังไม่มีตัวอ่าน Excel และถ้าเพิ่ม dependency ต้อง `npm install` ซึ่งเขียน `package-lock.json` ใหม่หลายพันบรรทัดในการเปลี่ยนเดียว ขอดูก่อนว่าใช้ CSV แล้วติดขัดจริงหรือไม่
